# QR 패널 (QR Panel)

이미 만들어 둔 Quick Reply(QR)를 **별도 패널**에서 실행하는 SillyTavern 확장이에요.
결과는 **채팅별로** 저장되고, 본 채팅이나 본 대화 프롬프트에는 기록되지 않아요.

## 설치 (비공개 GitHub 저장소)

1. GitHub에서 이 저장소만 읽을 수 있는 Fine-grained 토큰을 만들어요 (Contents: Read-only).
2. ST의 확장 프로그램 → **Install extension**에 `https://토큰@github.com/romantic-lamb/st-qr-panel`을 넣어요.
3. 새로고침한 뒤 마법봉 메뉴에 **QR 패널**이 보이면 성공이에요.

필요한 것: ST 기본 **Quick Reply** 확장. 연결 프로필을 쓰려면 기본 **Connection Manager**, Interpres 번역을 쓰려면 **Interpres**가 켜져 있어야 해요.

## 사용법

- **열기**: 마법봉 메뉴 → `QR 패널`, 또는 채팅창에 `/qrpanel`
- **팝업**: 기본으로 화면 가운데 큰 팝업으로 열려요. 바깥을 누르거나 Esc를 누르면 닫혀요. 넓은 화면에서는 왼쪽에 QR 목록, 오른쪽에 결과가 크게 나와요.
- **탭**: `실행`(QR 버튼과 결과) · `요약`(이 채팅의 요약 편집) · `설정`(모든 설정). 설정 탭 위쪽 칩으로 항목에 바로 이동해요. 확장 프로그램 설정 화면에도 같은 설정이 있고 서로 바로 맞춰져요.
- **창 모드**: 헤더의 창 모드 버튼을 누르면 팝업 → 오른쪽에 붙이기 → 떠 있는 창 순서로 바뀌어요. 설정 → 화면에서 고를 수도 있고, 팝업 크기(보통/크게/화면 가득)도 정할 수 있어요.
- **크기**: 설정 → 화면 → 글자와 버튼 크기 "보통 / 크게 / 아주 크게"
- **번역 중 표시**: 번역하는 동안 카드에 로딩 바와 진행 상태가 떠요. 번역은 한 번에 하나씩 차례로 보내고, 모델이 "요청이 너무 많다"(429)고 하면 잠시 기다렸다 최대 두 번 다시 시도해요.
- **QR 그룹**: 그룹 이름을 누르면 접히고 펼쳐져요. 위쪽 버튼으로 모두 접기·펼치기, 검색창으로 QR을 찾을 수 있어요.
- **순서 바꾸기**: `순서` 버튼을 누르고 그룹이나 QR을 끌어서 옮긴 뒤 `완료`를 눌러요. 패널 안에서만 바뀌고 Quick Reply 원래 순서는 그대로예요. 설정의 "패널 순서 초기화"로 되돌릴 수 있어요.
- **맥락 바꾸기**: 버튼 오른쪽 작은 표시(`최근 대화` / `요약` / `요약+최근`)를 누르면 바뀌어요. 버튼마다 따로 기억돼요.
- **결과 보기**: 결과 위쪽에서 `카드` / `목록`을 고를 수 있어요. 목록은 결과마다 한 줄(제목, 첫 줄 미리보기, 시간)로 정리되고, 누르면 그 자리에서 펼쳐져요. QR별 필터, 결과 검색, 최신순/오래된순 정렬, 모두 펼치기·접기가 있어요.
- **프리셋**: 연결 프로필을 고르면 옆에 프리셋 선택이 생겨요. 프로필에서는 API 연결(API, 모델, 주소)만 가져오고, 생성 설정은 고른 프리셋을 써요. 프로필마다 따로 기억해요. "현재 연결 사용"일 때는 지금 쓰는 프리셋을 그대로 써요.
- **연결 테스트**: 설정 탭 → 생성에서 `생성 연결 테스트`, 번역에서 `번역 연결 테스트`를 누르면 지금 설정으로 짧은 요청을 보내 봐요. 성공 여부, 걸린 시간, 실제 응답을 보여주고, 실패하면 오류 내용과 확인할 점(키, 주소·모델, 요청 한도, 서버 오류 등)을 알려줘요. 기록에는 남지 않아요.
- **요약**: `요약` 탭에서 직접 쓰거나 `AI로 요약 갱신`, `요약 확장에서 가져오기`를 눌러요.

## 스크립트 QR은 어떻게 실행되나요

패널에서 누른 스크립트 QR은 패널 안에서만 돌아요.

| 명령 | 패널에서 실행할 때 |
|---|---|
| `/send`, `/sendas`, `/sys`, `/comment`, `/setinput` | 채팅 대신 **패널에 결과로** 표시 |
| `/sysgen` | 패널 설정으로 생성해서 패널에 표시 |
| `/gen`, `/genraw` | 패널 설정(연결 프로필, 맥락, 출력 언어)으로 생성. 설정에서 끄면 ST 기본 방식 |
| `/trigger`, `/continue`, `/regenerate`, `/impersonate`, `/inject`, `/hide` 등 | **막음** (본 채팅을 바꾸는 명령). 카드에 막은 명령이 표시돼요 |

본 채팅 화면에서 직접 누른 QR, 자동 실행 QR은 원래대로 작동해요. 패널이 가로채는 건 패널에서 실행한 스크립트뿐이에요.
스크립트 안에서 `{{arg::context}}`를 쓰면 패널이 고른 맥락(최근 대화·요약)이 들어가요.

한계: 스크립트 안에서 `/qr`, `/run`으로 **다른 QR을 부르면** 그 QR은 패널 밖에서 실행돼요.

## 번역

설정 → 번역 → 번역 방식:

- **Interpres 설정 사용** (기본): Interpres의 언어(모델어→감상어), 말투 카드, 용어집, 독자 지시문, 번역 톤, 모델 연결(현재 API / 커넥션 프로필 / 커스텀 API / 리버스 프록시)을 그대로 써요. Interpres에서 프롬프트를 직접 고쳤다면 그 프롬프트를 써요. `{{매크로}}`, 코드, 링크, 지정 태그는 번역하지 않고 지켜요. 패널 번역은 Interpres의 번역 기억(캐시)에 저장되지 않아요.
- **슬래시 명령**: 번역 결과를 돌려주는 명령을 직접 넣어요. 예: ST 기본 번역 `/translate {{text}}`

## 저장 위치

- 실행 기록, 번역, 요약: 각 채팅의 메타데이터 (채팅 파일과 함께 저장)
- 설정 (프로필, 언어, 버튼별 맥락, 그룹 접힘, 순서, 지시문 등): ST 확장 설정

## AI 지시문

시스템 지시문과 요약 지시문은 영어로 되어 있고 설정에서 고칠 수 있어요. 출력 언어를 고르면 "Write your entire response in Korean." 같은 문장이 자동으로 붙어요.
