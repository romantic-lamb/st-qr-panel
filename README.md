# QR 패널 (QR Panel)

이미 만들어 둔 Quick Reply(QR)를 **떠 있는 별도 패널**에서 실행하는 SillyTavern 확장이에요.
결과는 **채팅별로** 저장되고, 본 채팅이나 본 대화 프롬프트에는 기록되지 않아요.

## 설치

1. 압축을 풀면 `st-qr-panel` 폴더가 나와요.
2. 이 폴더를 SillyTavern 안의 다음 위치에 넣어 주세요.
   - `SillyTavern/data/<사용자 이름>/extensions/st-qr-panel` (보통 사용자 이름은 `default-user`)
   - 또는 `SillyTavern/public/scripts/extensions/third-party/st-qr-panel`
3. SillyTavern 페이지를 새로고침해요.
4. 확장 프로그램 메뉴(블록 아이콘)에 **QR 패널** 항목이 생기면 성공이에요.

필요한 것: ST 기본 **Quick Reply** 확장(기본으로 켜져 있어요). 연결 프로필을 쓰려면 기본 **Connection Manager**, 번역을 쓰려면 쓰시는 번역 확장이 켜져 있어야 해요.

## 사용법

- **열기**: 마법봉 메뉴 → `QR 패널`, 또는 채팅창에 `/qrpanel` 입력
- **실행**: 패널의 QR 버튼을 누르면 결과가 패널에 쌓여요.
- **맥락 바꾸기**: 버튼 아래 작은 표시(`최근 대화` / `요약` / `요약+최근`)를 누르면 바뀌어요. 버튼마다 따로 기억돼요.
- **요약**: 패널의 `요약` 칸을 펼쳐서 직접 쓰거나, `AI로 요약 갱신` 또는 `요약 확장에서 가져오기`를 눌러요. 요약은 채팅마다 따로 저장돼요.
- **연결 프로필 / 출력 언어**: 패널 위쪽 두 드롭다운에서 바로 바꿀 수 있어요. 패널 프로필을 바꿔도 본 채팅 연결은 그대로예요.
- **번역**: 결과 카드의 `번역` 버튼을 눌러요. 다시 누르면 원문과 번역을 오갈 수 있어요. 설정에서 자동 번역을 켤 수도 있어요.

## 번역 명령 설정

설정의 **번역 명령**에 쓰시는 번역 확장의 슬래시 명령을 넣어 주세요. `{{text}}` 자리에 패널 결과가 들어가요.

| 번역 확장 | 번역 명령 |
|---|---|
| ST 기본 번역 (Chat Translation) | `/translate {{text}}` (기본값) |
| 언어를 직접 지정하고 싶을 때 | `/translate target=ko {{text}}` |
| 다른 번역 확장 | 그 확장의 슬래시 명령. 번역 결과를 돌려주는 명령이어야 해요 |

## QR 종류별 동작

- **일반 문장 QR** (예: `{{char}}의 속마음을 묘사해줘`): 이 문장이 지시문이 되고, 고른 맥락과 함께 AI에 보내져요.
- **스크립트 QR** (`/`로 시작): 스크립트를 그대로 실행하고, 마지막 명령의 결과를 패널에 보여줘요. 맥락은 `{{arg::context}}`로 쓸 수 있어요.
  - `/send`, `/sendas`, `/sys`, `/trigger`, `/inject` 같은 명령은 채팅이나 본 프롬프트에 직접 쓰기 때문에 패널이 막을 수 없어요. 이런 QR은 실행 전에 경고창이 떠요.
  - 스크립트 안의 `/gen`은 패널 설정이 아니라 ST의 현재 연결과 본 채팅 맥락을 써요.

## 저장 위치

- 실행 기록과 요약: 각 채팅의 메타데이터 (채팅 파일과 함께 저장)
- 설정 (프로필, 언어, 버튼별 맥락, 지시문 등): ST 확장 설정

## AI 지시문

시스템 지시문과 요약 지시문은 영어로 되어 있고, 설정에서 고칠 수 있어요(`기본값으로 되돌리기` 버튼 있음). 출력 언어를 고르면 "Write your entire response in Korean." 같은 문장이 자동으로 붙어요.
